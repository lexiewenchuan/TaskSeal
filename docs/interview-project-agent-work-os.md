# TaskSeal：面试项目说明

> 项目定位：TaskSeal 是一个以任务本体为语义基础、以有限授权和证据验收为核心、支持多种 Agent Runtime 和受控经验成长的通用 Agent 工作框架。Agent Work OS 是它的架构类别，而不是项目名称。

## 一句话介绍

普通 Agent 框架主要解决“Agent 怎样思考和调用工具”，这个项目继续解决：

> 当 Agent 开始修改代码、文档、数据和线上系统时，怎样让多个 Agent 在明确权限下协作，并用证据证明目标真的完成。

## 为什么做这个项目

真实任务通常不会在一次模型调用中结束：

- 一个目标会被拆成多个子任务；
- 任务可能跨模型、跨会话、跨天执行；
- 多个 Agent 可能同时读取或修改同一资源；
- Agent 返回成功，不代表外部资源真的正确；
- 历史记忆可能已经过期；
- 自我改进可能提高一个指标，同时破坏安全性或已有能力。

因此，项目不把“对话”或“一次 Agent Run”作为顶层对象，而是建立长期存在的任务单。

## 核心设计

### 1. 任务单

任务单保存目标、范围、风险、方案、权限、状态、产物、证据和验收结果。

它独立于模型和对话线程，因此可以暂停、恢复、更换执行者和回放全过程。

### 2. 任务本体

框架统一定义目标、任务、主体、能力、资源、动作、授权、产物、证据和验收之间的关系。

它让规划、权限、执行、记忆和验收模块使用同一种语言，同时允许软件工程、文档、数据和运维领域扩展自己的对象。

### 3. 有限授权

委派不是把一段 Prompt 发给子 Agent，而是明确：

```text
允许谁
在什么时间内
对哪些资源
执行哪些动作
满足什么条件
```

所有真实副作用都经过资源操作入口再次检查，子 Agent 不能获得超过父任务的权限。

### 4. 证据验收

项目区分产物、观察结果、证据和已确认事实。

执行成功不会直接关闭任务。只有当证据逐项支持验收标准后，任务才能完成。

### 5. 受控成长

任务轨迹可以被整理为案例，并生成候选技能、模板、规则或调度策略。

候选能力必须经过隔离评测、回归检查、风险审查、小范围试用和可回退晋升，不能在真实环境中自由改写自身。

## 四个闭环

```text
决策闭环：目标 → 任务 → 上下文 → 方案 → 风险
执行闭环：授权 → 调度 → 执行者 → 资源操作
验收闭环：产物 → 证据 → 独立检查 → 完成或修复
成长闭环：轨迹 → 案例 → 候选能力 → 评测 → 晋升或回退
```

前三个闭环保证当前任务可信完成，第四个闭环让未来任务做得更好。

## 与常见 Agent 框架的关系

Codex、LangGraph、OpenAI Agents SDK、Raven 或固定程序都可以成为执行环境。

本项目不重复实现模型调用和 Agent Loop，而是在其上提供：

- 跨运行时任务状态；
- 资源和能力目录；
- 风险策略与有限授权；
- 统一副作用入口；
- 证据和独立验收；
- 受控能力晋升。

## 面试时建议怎样讲

### 30 秒版本

这是一个面向真实工作的 Agent 控制框架。普通 Agent 框架解决模型怎样调用工具，我解决一个目标怎样经过任务建模、风险判断、有限授权、多 Agent 执行和证据验收后可信完成。任务完成后的轨迹还可以进入受控成长流水线，只有经过评测和小范围验证的经验才能升级为正式能力。

### 3 分钟版本

1. 从“Agent 返回成功不等于任务完成”讲问题。
2. 介绍任务单为什么必须独立于对话和一次运行。
3. 讲规划、授权、执行、证据和验收四个关键边界。
4. 讲任务本体怎样支持跨领域和不同 Agent Runtime。
5. 最后讲受控成长：不是禁止自我改进，而是把它变成可评测、可暂停、可回退的能力发布流程。

## 适合继续追问的技术问题

- 任务状态怎样通过事件日志恢复；
- 授权怎样绑定主体、资源、动作和有效期；
- 多 Agent 怎样避免资源写冲突；
- 证据怎样绑定资源版本和验收项；
- 记忆怎样区分事实、参考和过期信息；
- 如何设计隔离评测，避免候选能力看到测试答案；
- 如何判断新能力的收益是否值得增加的成本和风险；
- 如何将不同 Agent Runtime 适配为统一执行协议。

## 当前边界

当前成果是架构设计和工程约束，不把尚未实现的模块描述成已经上线的能力。

作为面试项目，下一步应该选择一个具体场景实现最小闭环，例如：

```text
代码修改任务
→ 生成方案
→ 发放目录级权限
→ 调用 Coding Agent
→ 收集代码差异和测试结果
→ 独立验收
→ 记录任务轨迹
```

最小实现只需证明框架的核心差异，不需要一次完成全部六层。
